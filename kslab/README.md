# kslab — 공유 라이브러리

두 실험 트랙([`restoration/`](../restoration/README.md), [`guardrail/`](../guardrail/README.md))이 함께 쓰는 코드다.
러너(`<트랙>/exp/run_*.py`)는 이 패키지를 조립할 뿐 자체 로직을 거의 갖지 않는다. 각 모듈이 하는 일은 모듈
docstring을 본다.

이 패키지는 이 실험 저장소 전용이다. k-safeguard 저장소는 읽기 전용으로만 참조하고, 그쪽에는 아무것도 쓰지 않는다.

## 지키는 것

대부분 테스트(`tests/`)와 런타임 검사가 강제한다. 바꾸려면 해당 테스트부터 고친다.

- **평가 데이터는 학습에 들어가지 않는다.** 학습 데이터를 만드는 함수는 평가 원문과 외부 생성기를 받지 않는다.
- **모든 난독화 기법은 통합 분류표의 한 유형에 속한다.** 실험 결과는 기법이 아니라 유형으로 집계한다.
- **난독화 문장은 레시피로 다시 만들 수 있어야 한다.** 그래야 결과를 재현하고, 바뀐 글자마다 어느 기법 때문인지 안다.
- **분할은 출처 단위로 나눈다.** 같은 출처(템플릿·문서)의 문장이 학습·평가 양쪽에 들어가면 성능이 부풀려진다
  (랜덤 분할은 중성 슬롯 정확도를 15%p 부풀렸다).
- **복원기가 고칠 자리는 입력만 보고 정한다.** 정답과의 차이를 쓰면 정상 문장 오변경이 실제보다 좋게 나온다.
- **자모 테이블은 k-safeguard 원본과 같아야 한다.**
- **외부 생성기는 학습에 쓰지 않는다.** 외부 생성기 저장소마다 가상환경을 따로 두고(의존성 버전이 서로 다르다),
  재현에 쓴 커밋을 평가셋 헤더에 남긴다.

## 외부에 두는 것

- k-safeguard 저장소는 이 저장소와 같은 부모 폴더에 `k-safeguard/`로 둔다.
- 외부 난독화 생성기(KOTOX, kotka, korean-jamo-typo)는 `data/ext/` 아래에 받는다. 출처와 준비 방법은
  `kslab/external_gen.py`에 있다.
