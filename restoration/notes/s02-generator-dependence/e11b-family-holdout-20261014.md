## 왜 돌리나
외부 데이터 없이 규칙 과적합을 숫자로 본다. 5개 기법군(된소리·연음·받침·동화·모음) 중 하나를
빼고 학습한 합집합 BiLSTM이, 그 기법군을 넣고 학습한 모델 대비 CER 감소를 얼마나 유지하는가.

- 예상(실행 전, Claude): 대부분 기법군에서 유지율이 50% 미만일 것이다. 근거는 E9 — 조합 실패의
  원인이 기법별 탐지 신호 소실이었고, 기법마다 흔적(경음 초성, 거센소리 초성 등)이 달라 한
  기법에서 배운 것이 다른 기법으로 잘 넘어가지 않을 것으로 본다. 예외 후보: 받침 계열(크래밍·
  중화·자음군)은 서로 비슷한 종성 변형이라 일부가 빠져도 남을 수 있다 — 단 기법군 단위로 빼므로
  이 예외는 기법군 안에서만 작동한다.
- 결과별 대응: 평균 유지율 < 50% → 생성기 확장(KOTOX 규칙 이식·무작위화)을 다음 단계 우선으로.
  ≥ 50% → 생성기 의존이 덜 심각하니 탐지기 분리(e11d 결과와 함께)를 먼저 검토.

## 무엇을 바꿨나
- s01(E8b) 대비: 단일 기법 모델 → 13개 기법 합집합 모델(후보 = 모든 음절, 슬롯 = 초·중·종).
- 학습 예산 고정: 모델당 페어 약 240,000개(기법별 문장 수 = 예산 / (기법 수 × 3)). 제외 모델은
  남은 기법을 조금 더 많이 본다.
- 임계값: 505 시드가 아니라 benign dev 문장 변형률 목표(0·0.5·1·2·5%)로 정한다. 헤드라인 1%.
- 시드 3개(2026·2027·2028), 데이터 생성 시드 1234 고정.
- GPU 학습(`device=cuda`). 같은 설정에서 CPU와 비트 단위로 같지 않다 — 소규모 비교에서 CER 감소
  5.04 vs 5.48%p(드롭아웃 난수열 차이, 시드 차이 수준).
- BiLSTM 크기는 E8b와 같다(max_len 96, embed 96, hidden 112, 2층, batch 128, 5 epoch).
- 학습 6구성(전체 + 5개 기법군 각각 제외) × 시드 3 = 18회.
