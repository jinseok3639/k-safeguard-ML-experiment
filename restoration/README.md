# 복원기 실험 트랙

난독화된 한국어를 원문 후보로 되돌리는 복원기를 실험한다.

- **주 목적**: k-safeguard에 탑재될 복원기의 성능 최대화.
- **부 목적**: 복원기가 다루는 난독화 종류(커버리지) 확대.

진행 상황과 결론은 [`EXPERIMENTS.md`](./EXPERIMENTS.md), 1기(E0~E10) 종합은 [`reports/SUMMARY.md`](./reports/SUMMARY.md)에 있다.

## 이 트랙의 규칙

- **평가 데이터는 학습에 쓰지 않는다.** 외부 생성기에서 약한 모양을 학습 생성기에 넣을 때도 그 생성기의 문장은 쓰지 않고,
  한 외부 생성기에서 가져온 모양은 다른 외부 생성기로 확인한다. 시험지를 따라 만든 생성기로 그 시험지를 채점하지 않기 위해서다.
- **복원기는 후보만 낸다.** block/allow 판단은 하지 않는다.
- **가드레일 실측은 가드레일 트랙과 나눠 본다.** 복원기를 실제 가드레일에 물려 재는 실험은 이 트랙에 두고(복원기가 대상),
  가드레일 자체를 고르거나 비교하는 실험은 [`guardrail/`](../guardrail/README.md)에 둔다.

## 판정 기준

- **정상 문장을 바꾸지 않는 것이 먼저다.** 난독화되지 않은 정상 문장을 바꾸는 비율(오변경)은 1% 이하여야 한다(k-safeguard
  `EVALUATION_SPEC.md` §11.4). 복원을 아무리 잘해도 이걸 못 지키면 탑재하지 않는다. 표본이 작으면 비율만 보지 말고 신뢰구간과
  서로 다른 오류 단어 수를 함께 본다.
- **복원은 문장마다 재서 평균한다.** 글자 오류율 개선을 %p로 평균하면 입력이 얼마나 망가졌는지에 따라 값이 흔들린다.
  문장마다 손상 중 되돌린 비율, 글자 단위 정밀도·재현율, 문장 결과(완전 복원·나아짐·같음·나빠짐)를 본다.
- **유형별로, 난이도별로 나눠 본다.** 평균이 좋아도 특정 유형이나 섞인 문장에서 무너질 수 있다.
- **우리가 만들지 않은 생성기가 주 시험이다.** 자체 생성기 성능은 학습이 됐는지만 보여 준다.
- **비교는 지금까지 가장 나은 설정과 같은 지표로 한다.** 시드 범위를 넘는 차이만 차이로 본다.
- **지연은 CPU에서 문장 하나 p95로 잰다.** k-safeguard 예산 안이어야 한다.
