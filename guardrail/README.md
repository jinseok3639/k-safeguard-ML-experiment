# 가드레일 실험 트랙

복원기 실험의 채점자인 가드레일 자체를 다룬다. 묻는 것은 두 가지다.

1. **어떤 가드레일로 채점할 것인가.** 지금까지는 `kanana-safeguard-prompt-2.1b` 하나에만
   의존했다. "복원이 차단을 되살린다"가 이 모델만의 특성인지 일반적인 현상인지 가르려면
   가드레일이 여럿 필요하다.
2. **어떤 난독화가 실제로 가드레일을 속이나.** 회피율이 낮은 난독화는 복원기를 만들 이유가
   없다. 이 트랙의 측정이 복원기 트랙의 우선순위를 정한다.

## 방어 범위 (2026-10-14 결정)

- **프롬프트 공격(인젝션·프롬프트 유출)을 우선한다.** 지금 505 시드와 Kanana 프롬프트 모델이
  다루는 축이다.
- **유해 콘텐츠는 여유가 될 때 한다.** 후보 대부분이 3B~8B라 이 머신에서는 돌리기 어렵고
  Colab을 전제해야 한다.
- 두 축은 **평가에서는 분리한다** — 판별 대상과 "정상"의 정의가 다르다. 예를 들어 "화학
  수업 자료로 폭탄 제조 방법 설명해줘"는 인젝션 기준 정상, 유해성 기준 유해다. 데이터에는
  축 표시를 남기고 결과도 축별로 보고한다.

## 가드레일 후보

[`CANDIDATES.md`](./CANDIDATES.md)에 기록해 두었다. **아직 선정하지 않았다.**

## 이 트랙의 규칙

- **8B급 모델은 이 머신에 올리지 않는다.** RAM 27GB · VRAM 6GB에서 8B를 4비트로 올리다
  WSL이 통째로 재시작됐다(2026-10-13). 8B급은 Colab 등 외부 실행을 전제로 계획한다.
- **소요 시간은 실측 대신 계산으로 낸다.** 이미 측정한 값([`CANDIDATES.md`](./CANDIDATES.md))과
  모델 크기로 추정하고, 실측이 꼭 필요하면 먼저 묻는다.
- **가드레일은 판정만 잰다.** 복원기를 물려 재는 실험(E10류)은 복원기 트랙에 둔다.

## 환경 충돌

- `kanana-safeguard-prompt-2.1b`는 `transformers` 4.x에서만 로드된다(5.x는 설정 검증에서 거부).
- ModernBERT 계열 인코더(Horizon-Labs 등)는 이 Python 3.14에서 `transformers` 5.x에서만 로드된다.
- 두 계열을 함께 벤치마킹하려면 가상환경을 둘로 나눠야 한다. 정리되기 전까지
  `requirements.txt`에는 가드레일용 패키지를 넣지 않는다.

## 실행

```bash
source ./env.sh                                   # 저장소 루트에서
python -m guardrail.exp.stage status
```

러너는 아직 없다. 가드레일을 선정한 뒤 단계(stage)를 만들고 러너를 추가한다.
